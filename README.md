# Password Strength Checker 🔐

## Description

This is a simple **Password Strength Checker** built using **HTML, CSS, and JavaScript**.
The project checks the strength of a password as the user types and displays whether it is **Weak, Medium, or Strong**.

## Features

* Detects password input in real time
* Evaluates password strength based on length
* Displays strength message instantly
* Changes message color to indicate strength

## Technologies Used

* HTML
* CSS
* JavaScript

## How It Works

1. The user enters a password in the input field.
2. JavaScript reads the password length.
3. The program evaluates the strength using simple conditions.
4. The result is displayed as **Weak, Medium, or Strong**.
